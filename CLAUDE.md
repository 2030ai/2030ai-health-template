# Инструкции для Claude Code (CLAUDE.md)

Этот файл расширяет `AGENTS.md` спецификой Claude Code: какие скиллы использовать, какие MCP подключать, как не ломать приватность.

## Основной скилл

- [`health-update`](.claude/skills/health-update/SKILL.md) — единая точка входа для сбора и обработки health-данных из всех источников.

Триггеры: `/health-update`, `"обнови здоровье"`, `"проверь здоровье"`, `"собери данные"`, `"health update"`.

## MCP, которые стоит подключить

| MCP | Назначение | Обязателен? |
|---|---|---|
| `google-mcp-readonly` | Gmail / Drive / Calendar / Sheets read-only | Нет, но ускоряет сбор из Gmail |
| `telegram-read` | Читать Telegram (личные заметки, медиа) | Нет, нужен только если вы ведёте заметки в Telegram |
| Без дополнительных MCP | Вариант с ручным дропом файлов в `inbox/` | Работает с базовыми Read/Write/Bash |

Все MCP — только read-only по умолчанию. Write-операции против Gmail/Telegram (отправка, редактирование) **не требуются** для этого проекта.

## Запрещено

- Коммитить в git: PDF, фото, DICOM, raw CSV-экспорты, `.env`, личные токены.
- Публиковать репозиторий как публичный без явного разрешения пользователя.
- Пушить данные наружу (GitHub Gist, Pastebin, публичные draft-PR, упомянуть пациента в commit message).
- Удалять файлы из `inbox/` до подтверждения, что оригинал скопирован в `<ORIGINALS_DIR>`.
- Ставить медицинские диагнозы и рекомендовать конкретные препараты. Разрешено — описывать отклонения и советовать обратиться к врачу.

## Рекомендации по Claude Code

- **Не входить в plan mode** без явного запроса пользователя.
- **Не задавать лишних вопросов** — принимать решения самостоятельно в рамках AGENTS.md. Запрашивать только действительно неочевидное (путь к `<ORIGINALS_DIR>`, имя Telegram-чата, язык заметок).
- **Большие файлы** читать chunked через `Read(offset, limit)`.
- **Проверять git status** после каждой операции с побочными эффектами.
