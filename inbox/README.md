# inbox/

Сюда кладутся **сырые файлы** для последующей обработки ИИ-агентом:

- PDF с анализами (из Gmail-attachments, личных кабинетов лабораторий, порталов).
- Фото упаковок лекарств, фото страниц медкарты, скриншоты.
- CSV-экспорты из устройств (Apple Health через Shortcuts, Fitbit, Oura, Garmin).
- Текстовые заметки — копипаст из Telegram, Apple Notes.
- Bulk-экспорты (OneNote, Notion) при исторической миграции.

## Workflow

1. Положите файл сюда.
2. Запустите `/health-update` (Claude Code) — или скажите агенту: "обработай inbox".
3. Агент создаст структурированную `.md`-запись в `data/<type>/`, скопирует оригинал в `<ORIGINALS_DIR>/<type>/` и удалит файл из `inbox/`.

## Что НЕ класть

- Нельзя коммитить содержимое `inbox/` — всё, кроме `README.md` и `.gitkeep`, игнорируется `.gitignore`.
- Файлы, на которые нужна публичная ссылка (не ваш случай, но на всякий — они идут отдельно, не через health-pipeline).

## Что делать, если агент не удаляет файл

Скорее всего, он не смог подтвердить, что оригинал уехал в `<ORIGINALS_DIR>`. Проверьте:

```bash
ls <ORIGINALS_DIR>/<type>/   # есть ли файл?
```

Если есть — можно удалить из `inbox/` вручную. Если нет — скопируйте и потом удалите.
