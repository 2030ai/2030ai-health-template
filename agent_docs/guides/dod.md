# Критерии завершенности (DoD)

Минимальный DoD для любой задачи:

- [ ] Функционал работает согласно требованиям
- [ ] Документация обновлена, включая `agent_docs/development-history.md`

Дополнительно по типам задач (если применимо):

## Новые данные
- [ ] Файл создан с корректным frontmatter (все обязательные поля)
- [ ] Оригинал перемещён в `<ORIGINALS_DIR>`
- [ ] Провенанс заполнен (для не-manual источников)
- [ ] Wiki-links на связанные записи (визит → анализ → лекарство) расставлены

## Шаблоны / dashboards
- [ ] Корректный YAML frontmatter
- [ ] Dataview-запросы протестированы в Obsidian

## Документация
- [ ] Информация актуальна
- [ ] Ссылки работают

## Приватность
- [ ] Никаких чувствительных данных (ФИО врача, номер полиса, адрес клиники) не попало в публичные места (commit message, issue, PR).
- [ ] Оригиналы НЕ в git.
